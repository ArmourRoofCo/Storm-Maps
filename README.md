# Storm-Maps

Interactive storm lead map for Armour Roof Co., published with GitHub Pages.

The live map is [https://armourroofco.github.io/Storm-Maps/](https://armourroofco.github.io/Storm-Maps/). `index.html` is a self-contained Folium map (Leaflet and tiles load from CDNs), centered on the Omaha area, with Hail (red), Wind (blue), and Rain (green) lead layers from the 2026-10-15 strict snapshot.

`storm_leads_map.kml` is the same lead set for Google Earth and other KML clients. `.nojekyll` keeps GitHub Pages from processing the site with Jekyll.
